# VF520 — PROJECT_SCOPE

## 项目名称
VF520 投影仪完整商品项目

## 最大目标
基于真实 VF520 产品资料与可追溯素材，完成：资料整理、产品锚点管理、竞品/历史图分析、Ozon/WB 商品图规划与生图、标题/描述/标签词、商品页与营销素材，并让任意新窗口可以从 GitHub + Google Drive 低损失接管。

## 当前范围
- 产品真实参数与结构锚点
- 历史图片审核
- 竞品图片审核与排序逻辑
- 3:4 商品图片体系
- 约 1.6:1 横幅
- Ozon/WB 标题、描述、标签/关键词
- 后续营销素材

## 资料分工
- GitHub：规则、当前状态、决策、坑点、图片审核记录、资产索引、交接说明。
- Google Drive：图片、Excel、PDF、DOCX、规格表等原始/大型文件。

## 最高证据规则
1. 厂家原始规格表 / 厂家明确补充回复：参数与功能优先证据。
2. 无文字真实产品图：产品结构与外观优先证据。
3. 历史宣传图、第三方图、旧说明书：仅作设计/营销参考，除非已单独确认。
4. 当前售卖版本必须以“白色 + LAN 网口版本”为准；某些旧白底背面图缺 LAN，不能原样作为当前接口结构。

## 明确禁止
- 不得把竞品外形混入 VF520。
- 不得凭空改变前脸、镜头、散热、按键、接口、遥控器结构。
- 不得宣传原生 4K、Wi‑Fi 6、自动对焦、自动梯形、立体声/双扬声器、20W 音响、激光、DLP、内置电池、Type‑C 整机供电、未确认的全封闭光机等。
- 不得把 Android 简写放在首图中造成“只支持安卓手机”的误解；需明确投影仪智能系统与 iPhone/Android 投屏是两件事。
- 不得仅凭聊天记忆继续重要设计；新窗口需读 CURRENT_STATE + NEW_WINDOW_HANDOFF，并重新打开关键视觉锚点。
