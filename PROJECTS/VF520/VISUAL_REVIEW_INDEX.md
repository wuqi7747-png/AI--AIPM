# B. 竞品已看图的可继承结论

## KOR
已实际查看至少：Main-01、02、03、04、05。

### 视觉结构
- 暖色/深色家庭环境；
- 投影幕承担体验感；
- 产品主体明显但不压满；
- 标题很大，文案少；
- 每张图一个主题；
- 附图按“大屏 / 亮度 / APP / 使用体验”等拆开。

### 借鉴
- “一图一个购买理由”；
- 体验优先，参数后置；
- 家庭影院语义强。

### 不照搬
- 任何其产品结构或其独有参数。

## Q8 / INTIMOLOGY
已实际查看代表图：20、21、22、23、35；其中用户确认 **35 是主图**。

### 视觉结构
- 红/黑或高对比强氛围；
- 产品占比很大；
- 大字、大数字；
- 信息密度明显高于 KOR/Wanbo；
- 强调 4K、系统、应用、娱乐设备等。

### 借鉴
- 手机缩略图里的抓眼能力；
- 产品放大；
- 关键数字层级。

### 不借鉴
- 参数墙；
- 原生 4K 暗示；
- AI / 自动功能 / 未确认参数堆砌；
- 过度红色压迫感。
