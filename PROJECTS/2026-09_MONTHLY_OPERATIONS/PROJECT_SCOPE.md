# PROJECT_SCOPE — 2026-09 月度运营规划

## 项目名称
2026-09 月度运营与10月到货准备

## 最大目标
在 2026 年 9 月至 10 月上旬完成当前最关键的运营准备，使 10 月到达俄罗斯的 8 款测品玩具具备可直接上架的图片素材，同时在实际作图过程中迭代商品图技能；不影响日常店铺运营，并提前完成 12 月 10 日前到货批次的采购决策。

## 核心范围
1. 中秋节假期前完成 8 款测品玩具整套商品图。
2. 以这 8 款产品为真实案例，持续优化 GitHub 中的商品图制作技能/SOP。
3. 每日查看店铺运营数据，并填写销量等日常数据。
4. 每周一完成周报。
5. 规划后续采购：常规货按 40 天生产 + 30 天运输；新增测品按约 30 天制作 + 30 天运输。
6. momoshe VK 发帖自动化项目在 10 月前完成即可，优先级低于玩具作图和采购。
7. API 能力继续完善；每日表和周报自动化以现有 API 实际可用字段为基础逐步落地。

## 暂缓事项
- VF520：本阶段暂停，不投入主要时间。
- 运营数据中心：等待 API 完整度进一步提高后再集中建设。

## 明确禁止
- 在 8 款玩具图片完成前新增大量非必要项目。
- 为追求 API 接口覆盖率而偏离每日表、周报等真实运营需求。
- 作图过程中使用未经确认的产品结构、功能或配件信息。
- 将实验中的作图规则直接视为成熟生产规则；必须经过多款商品验证后再固化。
