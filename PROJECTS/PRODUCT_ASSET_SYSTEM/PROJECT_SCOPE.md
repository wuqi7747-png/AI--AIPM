# 商品图与产品资产系统｜PROJECT_SCOPE

## 最大目标

建立一套跨对话稳定可续接的商品图与产品长期资产系统，使任何新窗口无需依赖旧聊天记忆即可：

1. 找到正确商品/颜色/SKU的 Google Drive 资产目录；
2. 读取真实性锚点、源资料、已确认卖点、关键词与最终商品图；
3. 按统一结构继续作图、Listing 与后续 VK/视频任务；
4. 所有目录/映射变更在 GitHub 与 Drive 入口索引中同步。

## 权威来源

- 项目管理中心：`wuqi7747-png/AI--AIPM`
- 商品图 ACTIVE 规则与 Drive 实例映射：`wuqi7747-png/ozon-WB`
- 实际大文件与图片资产：Google Drive `AI商品图与内容资产系统`

## 边界

- GitHub 不复制图片/PSD/大文件。
- Drive 不作为 ACTIVE 流程规则的最高事实源。
- 具体产品已确认卖点保存在对应 `03_详情图/00_已确认卖点`，GitHub只维护其规则和位置。
- 多颜色商品按颜色/SKU独立管理，父目录仅负责分组。
